## Security/privacy findings

Local-only P0 transmits no diary data. IndexedDB is browser-local and can be evicted; users are warned to export backups. CSP is useful defense-in-depth but meta CSP cannot provide every server header; production hosting should add CSP, X-Content-Type-Options, Referrer-Policy and frame protection headers. Import is schema-validated but large local imports can still consume device storage; size cap is 20 MiB.
