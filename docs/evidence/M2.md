# M2 evidence — Hebrew RTL P0 application

Date: 2026-11-25  
Implementation commit: `8b53f6c`

## Implemented routes and behavior

- Onboarding creates profile, goal and initial effective-dated plan.
- Today dashboard uses repository-backed plan, food totals, latest measurement, habit check-in and deterministic coach summary.
- Nutrition diary supports local search, quick add, manual consumed-total entry, custom foods, quantity edit, soft-delete undo, explicit completion/invalidation, meal templates and recipe creation/consumption.
- Check-in saves preferred manual weight/waist measurements plus steps, water, sleep, training, hunger, energy and notes; blank means unknown.
- Settings edits profile/goal/units/timezone, creates immutable effective-dated plan revisions, exports JSON and detailed/summary CSV, imports FORM JSON or legacy JSON with dry-run/merge/replace, and clears local data after double confirmation.
- Hebrew RTL shell, logical CSS, mobile bottom navigation, desktop right rail, dark/light themes, visible focus, skip link, reduced-motion support and dialog Escape/focus trapping/restoration.
- Deferred cloud/auth/provider/barcode/native controls are absent rather than dummy controls.
