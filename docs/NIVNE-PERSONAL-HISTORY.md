# NIVNE / personal history

Local display name and optional email are not authentication. Vercel access protection is separate; no credentials, remote API, or personal data in source. Both identity and read-only source archive are included in full backups, missing legacy fields preserve local data. New archive import replaces only the archive, with explicit confirmation; same-date native logs remain separate and daily rhythm counts date once. Never combine overlapping volume totals. Historical analytics recompute nominal external load from confirmed units and basis; disputed, bodyweight, and unknown loads excluded. Fractional reps are bookkeeping, approximate reps marked, unquantified partials excluded. Exact equipment identity still requires confirmation. No medical recommendation or automatic training target. Native workout editor remains v1. Browser and physical phone testing required before production.
